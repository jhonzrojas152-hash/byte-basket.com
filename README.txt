BYTE & BASKET - WEBSITE FILES

This folder contains the HTML-only Byte & Basket school website.

HOW TO OPEN
1. Keep all files in this folder together.
2. Double-click index.html to open the website in your browser.
3. Test the menu links, the Google Drive portfolio links, and the email link.
